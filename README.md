# Instinct AI — MVP

نسخة أولى من مساعد ذكي بواجهة عربية، وخادم Node.js يتصل بـ OpenAI Responses API.

## المتطلبات
- Node.js 20 أو أحدث.
- مفتاح OpenAI API صالح.

## التشغيل محليًا
1. انسخ `.env.example` إلى `.env`.
2. ضع المفتاح في `OPENAI_API_KEY` داخل `.env` فقط.
3. شغّل `npm start`.
4. افتح `http://localhost:3000`.

لا ترفع ملف `.env` أو المفتاح إلى GitHub.

## النشر
انشر المشروع على خدمة تدعم Node.js 20، واضبط:
- `OPENAI_API_KEY` — سرّي، من إعدادات الاستضافة فقط.
- `OPENAI_MODEL` — اختياري، الافتراضي `gpt-4.1-mini`.
- `PORT` — غالبًا تضبطه منصة الاستضافة تلقائيًا.

أمر التشغيل: `npm start`.

## الموجود حاليًا
- واجهة محادثة عربية متجاوبة.
- اتصال خادمي؛ المفتاح لا يصل للمتصفح.
- ذاكرة محادثة مؤقتة لكل جلسة، وتُمسح عند إعادة تشغيل الخادم.
- حد لحجم الرسالة ومعدل الطلبات.
- فحص حالة الخادم من `/api/health`.

## حدود النسخة
هذه نسخة MVP أولية: لا تنفّذ أوامر على جهازك أو GitHub، ولا تتصفح الإنترنت، ولا تملك بعد نظام أدوات. أي إجراء خارجي يحتاج تكاملًا منفصلًا وموافقة واضحة واختبارات أمان.

## الفحص
شغّل `npm run check`.
